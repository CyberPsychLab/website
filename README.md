# CyberPsych Lab website

Source for **https://cyberpsychlab.com**, the website of the CyberPsych Lab in Columbia University's
Department of Psychology.

- **Want to update the site?** Read [docs/EDITING.md](docs/EDITING.md). No coding needed.
- **Using an AI assistant?** It will follow [CLAUDE.md](CLAUDE.md).
- **Maintaining the code, hosting, or DNS?** See [docs/MAINTENANCE.md](docs/MAINTENANCE.md).

Every change goes through a pull request. When it's approved and merged into `main`, the site
rebuilds and goes live automatically within a few minutes.
